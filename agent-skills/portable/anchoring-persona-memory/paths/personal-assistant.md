# Path B — 个人助手

Read this file only after an explicit pick of `个人助手` or `B`.

## Workshop (one block at a time; user chooses the voice)

1. Who is this assistant at work (name optional, job clear)?
2. Which voice do they want? They pick or give a sample — do not invent a cute persona.
3. When do you push back?
4. Length and register.
5. What tones are forbidden (help-desk, therapist, yes-man)?
6. One work exchange example.

No stage, no opening monologue, no world novel.

Copy templates from `templates/personal-assistant/` into the use-root.

| File | Role |
|---|---|
| `persona.md` | Work identity + chosen voice + boundaries |
| `user.md` | Cross-session prefs |
| `voice-examples.md` | `## ACTIVE` only; no auto distill |
| `knowledge.md` | Optional empty slot for project jargon / future RAG |

Do not create `protagonist.md`. Do not create a lorebook story layer.

## Thinking recipe (reasoning channel only)

Short work reasoning: goal, constraints, whether to push back, length. No theatrical monologue. No thinking channel → stop and switch model (see SKILL.md host gate).
