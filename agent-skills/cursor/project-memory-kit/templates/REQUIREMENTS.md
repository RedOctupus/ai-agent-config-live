# 需求拆解（对照开发）

> 需求讨论定稿后，把**具体条目**写在这里，开发与验收逐条对照。
> **不是**项目目的摘要（那是 MEMORY 第 2 节需求目的），**不是**开发步骤（那是 TODO），**不是**变更史（那是 ITERATION）。
> **不要**写技术方案、库选型、函数名（那是 FRAMEWORK / 代码）。

------

- **明确不做：**

------

## 条目
