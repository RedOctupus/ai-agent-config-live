# 项目框架

> 框架讨论定稿写这里：**技术选型、能力模块、分层**。
> 框架建立在各技术栈的选择之上。**每一项**技术栈必须已与用户商量并得到同意，才能写入「已定」。
> 不是项目目的（REQUIREMENTS / MEMORY 快照），不是端到端怎么走（FLOW），不是对方现在怎么办事（ENVIRONMENT）。
> 不写函数实现、不写文件清单（那是 Plan）。

未讨论前各节留空。大任务要进 Plan 或写代码时，若本文件仍空，或「已定」里有用户未确认的项，Agent 应先停下商量，不得当作框架已立。
