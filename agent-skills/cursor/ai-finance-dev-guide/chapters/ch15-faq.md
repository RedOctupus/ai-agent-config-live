# Chapter 15: 常见问题 FAQ

## Core Idea
团队运行中的四类高频问题用固定原则处理：进度、合并、答辩 Bug、加分项优先级。

## Frameworks Introduced
- **进度落后**: 日站会；落后 >2 天调分工或砍非核心（Won't/MoSCoW）。
- **合并不了**: 找模块 Owner，不删他人代码。
- **答辩 Bug**: 7.8 纪律 — 说明现象/原因/计划，**禁止现场改代码**。
- **加分项**: 基础闭环与必问句先绿，再做 GraphRAG/前端体验。

## Key Takeaways
1. Must 未闭环不做 Could
2. 冲突与合并在 Owner 机制下解决
3. 演示稳定性优先于功能炫技
