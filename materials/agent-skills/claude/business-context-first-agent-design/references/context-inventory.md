# Context inventory

| Class | Questions | Labels |
|---|---|---|
| Business | project, phase, area, work package, activity, current state? | known / simulated / assumed / unknown |
| Objects | events, documents, people, equipment, tasks, evidence? | known / simulated / unknown |
| Time | effective period, deadline, version, prior handling? | known / assumed / unknown |
| Rules | policy, regulation, permissions, human-only decision? | known / pending confirmation |
| Memory | prior cases, decisions, preferences, unresolved facts, conflicts? | read / write / not applicable |
| Evidence | source, timestamp, confidence, completeness, external-use eligibility? | sufficient / incomplete / unavailable |

Never silently fill a gap. Put it in the context index and choose: ask, simulate, defer, or stop.
