# Parallel collaboration suite（多人并行开发）

一套 1 总控 + 4 阶段技能，用于契约先行 / 兼容层 / Mock / 清理收敛。

| 技能 | 阶段 |
|---|---|
| `parallel-collaboration` | 总控路由 |
| `collaboration-contract` | 0 定契约 |
| `compatibility-layer` | 1 兼容层 |
| `mock-collaboration` | 2 Mock |
| `legacy-mock-cleanup` | 3 清理 |

安装到 Cursor：仅在明确要求时，把需要的子目录拷到 `~/.cursor/skills/<name>/`。默认只备份到本仓库，不自动注册到本机。
