## Questions

1. What starts this lifecycle?
2. What states can the business object occupy?
3. Which role owns each transition?
4. What evidence is required to move forward?
5. Which transitions are suggestions versus human decisions?
6. What happens when an input is missing, late, contradictory, or repeated?
7. What is the closure condition and what happens after closure?

## Cross-domain return

For every output, identify the downstream domain or project-level state it affects. If there is no consumer, the output may be a report rather than an operational capability.
