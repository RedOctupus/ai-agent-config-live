# 当日索引模板

复制为 `INDEX-YYYYMMDD.md` 后填写。本文件名带下划线，**不是**当日索引。

> **一天多件事**才建。一天一事 → 只写 `VERIFY-YYYYMMDD-短名.md`。
> **只放指针，禁止贴正文。** 战报 → VERIFY；坑 → HANDOVER；拍板 → ITERATION；待办 → TODO。

> **最小示例（可删）**：当天做了两件事，就在下表各放一个 VERIFY 指针，不贴正文。

**当天主战场：** （一句话）

| 事项 | 正文在哪 |
| --- | --- |
| （事项名） | `VERIFY-YYYYMMDD-短名.md` |
| （坑） | `HANDOVER.md` |
| （拍板） | `ITERATION.md` |
| （未闭环） | `TODO.md` |

判据：读完应知道那天发生了什么、去哪看细节。贴了正文 = 有份 VERIFY 没写。
