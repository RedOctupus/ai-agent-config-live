# Glossary — AI 金融项目开发指南

**ADR** — Architecture Decision Record：问题、候选、选择、原因、代价、复查条件 (Ch 4)

**Agent 五类型** — customer / advisor / risk / analyst / operator (Ch 1, 4)

**DoD** — Definition of Done，完成判定清单 (Ch 9)

**GWT** — Given-When-Then 验收写法 (Ch 3)

**MoSCoW** — Must / Should / Could / Won't 范围四档 (Ch 3)

**NL2API** — 自然语言提取参数经校验调业务接口 (Ch 1)

**NL2SQL** — 自然语言生成只读 SQL (Ch 1, 8)

**P0–P5** — 本项目六段落地排期 (Ch 5)

**RAG** — 检索增强生成，先查知识再答 (Ch 1)

**trace_id** — 全链路追踪 ID，反馈与审计关联 (Ch 4, 8, 14)

**三条闭环** — 知识、评测、反馈闭环 (Ch 0)

**七维差异** — AI vs 普通软件项目对比表 (Ch 0)

**九阶段流程** — 立项到运行迭代的企业主链路 (Ch 2)

**黄金测试集** — 固定输入/预期/风险级的基线评测集 (Ch 8)

**公共能力 Owner** — LLM 网关、权限、记忆等唯一维护人 (Ch 4)

**前缀缓存** — 稳定提示放前、易变输入放后以提高 cache 命中 (Ch 7)

**失败实验日志** — 与 ADR 并列记录错误尝试与防复发 (Ch 7)

**适当性** — 客户与产品风险等级匹配，确定性规则终裁 (Ch 3, 7, 8)

**门禁** — 阶段出口通过条件，未通过则回退 (Ch 2)

**场景卡** — 八字段用户场景描述模板 (Ch 3)

**幂等键** — 写操作防模型重试重复执行 (Ch 8)
