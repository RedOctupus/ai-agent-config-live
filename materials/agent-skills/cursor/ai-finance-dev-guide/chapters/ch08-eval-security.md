# Chapter 8: AI 评测、数据与安全治理

## Core Idea
先建**黄金测试集基线**再优化；工具调用服务端二次校验；数据最小化与脱敏；全链路版本与 trace_id 可观测；金融业务由确定性规则终裁。

## Frameworks Introduced
- **能力评测矩阵**: RAG、意图路由、工具调用、画像、投顾风控、NL2SQL、系统工程 — 各列核心指标与典型失败。
- **基线纪律**: P0 定阈值并记录结果；禁止测试结束后临时降标。
- **工具安全七条**: Schema 校验、权限/超时/重试、最大步数、读写分离、写操作二次确认与幂等键、风控规则终裁、审计日志。
- **数据治理**: 来源/Owner/敏感级别/保留期；知识库有效期；记忆隔离与删除；日志/Prompt 禁真实敏感数据。
- **可观测最小集**: 应用/模型/Prompt/知识库/规则版本 + 检索片段 + 工具 + Token + trace_id。
- **金融六底线**: 模型非合规结论、适当性链、冲突时风控从严、无依据拒答/转人工、风险提示、注入/越权/SQLi 等安全测试。

## Key Takeaways
1. 开发者临时几问不能代替固定评测集
2. 模型不能绕过适当性与权限检查
3. 变更 Prompt/知识库/规则/模型必重跑同一套测试
